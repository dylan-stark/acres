# acres-tui

A terminal explorer for the [Art Institute of Chicago's collection](https://api.artic.edu/docs/): search it live, browse the results beside each artwork drawn in color, read its wall label, filter, sort, save favorites with notes, and zoom and pan into the art.

```sh
acres-tui            # start on Highlights, then / to search
acres-tui --offline  # only what is already cached
```

`?` lists every key. Keys and settings can be changed in `config.json5` in the config directory, which `acres-tui --version` prints.

The [workspace README](https://github.com/dylan-stark/acres/blob/main/README.md#the-tui) covers the keys, the configuration and troubleshooting.
