# image-to-ascii-builder

A builder for the [`image-to-ascii`](https://github.com/kpberry/image-to-ascii) crate, with typed alphabets, fonts, metrics and conversion algorithms.

The [acres](https://github.com/dylan-stark/acres) tools now draw with [`charaoke`](../charaoke) instead. This crate is kept as the baseline that `charaoke`'s benchmarks compare against, and isn't developed further.
